## [0.2.0] - TBD

Reviewer revision accompanying the revised Scientific Data manuscript. Version DOI: TBD.

### Added

- Global axis convention: in the anatomical position X points to the subject's right, Y anteriorly and Z superiorly; every segment coordinate system is right-handed. Conversion rule for exchanged axis limits: u_new = 100 − u_old.
- Formal definition of segment frames (Gram–Schmidt construction) and normalized coordinates on the main page.
- Nominal-value note for the precision levels; sections "Scope of version 0.2", "Sensor orientation — reporting recommendations (non-normative)", "Relationship to existing standards" (precedence, hierarchical coordinate systems, graceful degradation), head fiducials vs. the 10–20 system, glossary and "How to cite".
- Use-case page: EMG-BIDS hierarchical coordinate systems, cross-modal foot example, ECG electrode V1.
- Reference schema `schema/v0.2/placement-record.schema.json` (JSON Schema 2020-12, non-normative) and controlled vocabularies `schema/v0.2/vocabularies.json` (MeasurementMethod, LandmarkIdentification, StandardReference); "Schema & vocabularies" page.
- Example files in `examples/` and a minimal EMG-BIDS dataset in `examples/bids_minimal/` (generated by `scripts/make_bids_minimal.py`).
- Validation script `scripts/validate_examples.py`, negative and edge test fixtures, and the `validate` GitHub Actions workflow.
- Reference implementation `unisep` (Python): `orthonormal_frame`, `normalized_coordinate`, `normalized_coordinates`; CLI `python -m unisep validate`.
- Consistency scripts: `scripts/table_inventory.py`, `scripts/compare_inventory.py` (changes against 0.1.1), `scripts/check_conventions.py` (axis convention).
- `CITATION.cff` and this changelog.

### Changed

- Every axis in the landmark table is written explicitly as `A (0 %) → B (100 %)`.
- Axis swaps to satisfy the global convention (example coordinates on these axes converted as 100 − u):
  - Torso-chest (2), Z: C7 → xiphoid process becomes xiphoid process (0 %) → C7 (100 %), along the longitudinal body axis in the anatomical position (pending decision D1). Examples IMU 2, Mocap 5, A, B converted (Z).
  - Abdomen (3), Y: midpoint ASIS → midpoint PSIS becomes midpoint of the PSIS (0 %) → midpoint of the ASIS (100 %). No examples.
  - Left upper arm (7), X: MHE → LHE becomes LHE (0 %) → MHE (100 %). Examples IMU 4, Mocap 7, D **not** converted (values already consistent with the new definition; pending author confirmation).
  - Right forearm (8), X: RSP → USP becomes USP (0 %) → RSP (100 %). Examples IMU 5, Mocap 8 converted; Mocap E unchanged (X = 50).
  - Left forearm (9), X: USP → RSP becomes RSP (0 %) → USP (100 %). Examples IMU 6, Mocap 9 converted; Mocap E unchanged (X = 50).
  - Right hand (4), X: RSP → USP becomes USP (0 %) → RSP (100 %). Example Mocap 10 converted.
  - Left hand (5), X: USP → RSP becomes RSP (0 %) → USP (100 %). Example Mocap 11 converted.
- Torso-chest (2), Y: wording clarified (C7 posterior → xiphoid process anterior; antero-posterior component); direction unchanged.
- Forearms (8, 9), Y: "Right-hand rule (limits: Olecranon Process → Cubital Fossa)" becomes olecranon (0 %) → cubital fossa (100 %), direction completing the right-handed system; direction unchanged.
- Foot (14, 15), Y: the 100 % landmark is the first metatarsal head (FMH), at the first metatarsophalangeal joint (pending decision D2); example values unchanged.
- HED note: HED strings are illustrative; HED-SLAM tags are not part of version 0.2.
- README: new title, repository structure, validation and citation.
- `paper.md`: note that version 0.2.0 supersedes the preprint where they differ.

### Fixed

- Foot landmark abbreviation "FME" (clash with the femur medial epicondyle) and its contradictory description (toe tip vs. first metatarsal head) replaced by FMH.
- Landmark-name typos ("processs" → "processes", missing spaces before parentheses).
- Segment count in the README ("15 body segments plus the neck").
- Outdated links to the former project domain and repository (website and README).
